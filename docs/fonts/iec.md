# IEC power symbols

[Category index](README.md) · [Integration rules](../font-reference.md)

Every Blit font draws these, from the glyph stack. Symbols use the terminal foreground colour. The glyph column uses your browser font, not the Blit rasterizer; codepoints/JSON are authoritative.
